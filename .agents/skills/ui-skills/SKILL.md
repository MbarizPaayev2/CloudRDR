# UI Skills — Design Engineering Toolkit

UI Skills provides design engineering recipes and best-in-class components for web applications.

## CLI Usage

```bash
# List all available skills and categories
npx ui-skills list

# List motion-specific skills
npx ui-skills list --category motion

# View a specific skill recipe (e.g. baseline-ui, craft, motion)
npx ui-skills get <slug>
```

## Principles

1. **Semantic Foundation First**: Build on accessible, robust semantic HTML before layering styles or animations.
2. **Smooth Physics & Springs**: Motion with natural easing and predictable micro-feedback.
3. **Responsive Craft**: Visual layouts adapt cleanly between desktop, tablet, and mobile screens.
