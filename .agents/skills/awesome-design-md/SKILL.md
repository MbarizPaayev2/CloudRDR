# Awesome DESIGN.md — Design System Specifications

Collection of curated `DESIGN.md` design system specifications from leading design-forward developer tools and tech brands.

## Available Design Systems

Detailed design system files are stored locally in `.agents/skills/awesome-design-md/design-md/`:
- **Vercel** (`design-md/vercel/DESIGN.md`): High contrast monochrome, ultra-fine 1px borders, subtle hover glows, Geist typography.
- **Cursor** (`design-md/cursor/DESIGN.md`): Dark IDE aesthetics, precise status markers, monospace data grids, low-saturation accents.
- **Linear** (`design-md/linear/`): Snappy micro-interactions, dark graphite canvas, subdued purple/indigo accents, keyboard shortcuts.
- **Supabase** (`design-md/supabase/`): Deep forest/emerald dark tones, emerald status badges, code-first data density.
- **Stripe** (`design-md/stripe/`): Seamless gradient accents, typography clarity, accessible focus rings.

## Core Rules for Developer Tool UI

1. **Color Calibration**: Deep base canvas (`#08090a` to `#0d1117`), high text contrast (`#ededed`), subdued secondary text (`#888888`), purposeful status indicators.
2. **Typography**: Inter/Geist for UI headings and body; JetBrains Mono or Fira Code for hashes, keys, timestamps, and numbers.
3. **Information Density**: Clear visual hierarchy without wasting viewport space. Avoid giant empty padding on dashboards.
