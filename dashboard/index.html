Security & Architecture Boundaries

Design principles enforcing zero trust and minimal attack surface

• Zero Plaintext Secrets: The agent consumes pre-signed session tokens and never requires AWS root or full cloud administrative keys.
• Read-Only Bucket Access: Only reads object metadata and calculates in-memory SHA-256 hashes without ever altering production files.
• Autonomous Tripwire Containment: Breaches of canary files dispatch instant IAM deny-all signals within < 4 seconds without operator lag.
